# CH3Plus Clean-Room Web Template

A GitHub-ready, clean-room React/Vite template inspired by a modern Thai streaming/news portal layout.

> This project does not contain proprietary source code, copyrighted assets, logos, or scraped content from CH3Plus. Replace mock data and assets with material you are authorized to use.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/components/` reusable UI components
- `src/pages/` page-level views
- `src/data/` mock content
- `src/styles.css` responsive styling
- `public/` static assets

Create a new repository and upload all files in this folder, or upload the ZIP contents after extracting it.
